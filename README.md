# Film Set (Il Set) — Italian 3 demo

Phone-style mini demo for Sue Scotto’s Italian Level 3 class. Students act as director and pick the correct tense for each storyboard shot: **Presente**, **Imperfetto**, or **Passato prossimo**.

## Demo film: *Al bar* (6 shots)

| # | Line (focus) | Correct |
|---|---|---|
| 1 | Sabato sera **eravamo** al bar… | Imperfetto |
| 2 | La musica **suonava** e tutti **chiacchieravano**. | Imperfetto |
| 3 | Improvvisamente **è arrivato** Marco. | Passato prossimo |
| 4 | **Ha ordinato** un caffè… e **si è seduto**. | Passato prossimo |
| 5 | Adesso Marco **racconta** una storia buffa. | Presente |
| 6 | **Era** tardi, ma nessuno **voleva** andare a casa. | Imperfetto |

## Run locally

Open `index.html` in a browser (no build step). Works offline once loaded.

## Help levels

- **More help** — English gloss + tense tip
- **Just right** — Italian + short context
- **Challenge me** — Italian only; soft hint after a miss

Preference saved in `localStorage`.
